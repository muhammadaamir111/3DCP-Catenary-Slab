# Gantry-Based 3D Concrete Printing of Formwork-Free Catenary Slabs

**National University of Sciences and Technology (NUST)**
Final Year Design Project | Team Leader: Muhammad Aamir | 2024 – Present

---

## 🏗️ Project Overview

This project addresses one of 3D Concrete Printing's (3DCP) biggest unsolved 
challenges — printing roofs and slabs **without costly formwork.**

By exploiting catenary geometry (a compression-dominant inverted curve), we 
eliminate the need for conventional formwork entirely, while simultaneously 
reducing steel reinforcement and enabling monolithic wall–slab construction 
on a standard 3-axis gantry printer.

---

## ⚡ Key Innovations

| Innovation | Description |
|------------|-------------|
| **Catenary Geometry** | Compression-dominant slab profile designed in SAP2000/ETABS — eliminates bending, reduces steel by 53% |
| **Variable Orientation Inclined Cap** | Enables standard 3-axis gantry to deposit angled layers along catenary curve |
| **Wet-State Vertical Interlock Joint** | Steel bars anchored into fresh-printed walls create formwork-free wall–slab continuity |
| **Kevlar Tension String System** | Pre-tensioned strings counteract horizontal arch thrust inherent to catenary geometry |

---

## 📊 Results

- ✅ **53% reduction** in steel reinforcement vs conventional flat slabs
- ✅ **PKR 1,680/m²** in formwork costs eliminated
- ✅ Wall and slab prototypes successfully printed and validated
- ✅ LVDT displacement testing confirmed structural integrity under loading
- 🔄 Seismic performance evaluation ongoing via SAP2000 & ABAQUS
